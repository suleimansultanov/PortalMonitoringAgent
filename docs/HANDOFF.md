## 3b. Stream.Estate V1 — платный, зачем и как

- **Зачем, если V2 бесплатный.** V2 начинается с 24.06.2026 и в заливе не несёт
  Propriétés Le Figaro, Figaro Immobilier и Superimmo. V1 несёт все три
  (проверено 14.10 на La Môle: из 25 объектов Figaro Immobilier 8, Superimmo 5,
  Propriétés 1) и держит объекты с 2022 года. Thomas (09.10, письменно): даты
  V1 — дата их первого обнаружения, не публикации; в `publishedAt` не пишем.
- **Как читает.** Адаптер `adapters/streamestatev1.ts`. Для коммуны без
  записей — склад (не expired, обновлён ≤30 дней). Дальше каждую ночь три
  запроса с момента прошлого прохода: created, re-priced, expired. Expired
  снимаются **по имени** через новый хук `ctx.gone` в `runner/run.ts`; конфиг
  `changesOnly` выключает abort guard и помечает проход неполным, чтобы
  ничего не снималось «за отсутствие». Les Issambres — по индексу 83380.
- **Сколько стоит.** Измерено бесплатными подсчётами 13.10: склад 5 455,
  в день ~131 created, ~26 re-priced, ~46 expired → первый месяц ~11 500,
  дальше ~6 000. Один объект, вернувшийся дважды, оплачивается дважды.
- **Счётчик.** `streamV1.ts`: журнал `api_usage` (append-only), потолок
  `monthlyItems − reserve` = 14 000, кэш ответов на диске только у CLI
  (`.pages/stream-estate-v1/responses/`), платный запрос без повтора: если
  оборвался — считается по максимуму и всё останавливается. Бесплатный
  подсчёт, вернувший данные, тоже останавливает всё. Сверка с их кабинетом
  сделана на одной странице La Môle 14.10 (27 items).
- **История цен** (`npm run stream:history`): семейство `price-changes` —
  10 174 объекта с изменением цены с июля 2021 — помещается в план, но не
  вместе со складом в один период. Отложено на следующий период (с 14.11),
  когда ночной расход будет ~6 000. Импорт истории в базу ещё не написан.
- **Не делать:** полный проход по V1, `includedSites` (формат значений
  неизвестен, все пробы вернули 0 — спросить Thomas: это сократило бы
  расход до одних Figaro), ключ V1 в чат.

## 6. Ловушки этой машины и процесса

- **Трафик.** Оператор часто на мобильном интернете. `reparse` качает из S3
  все страницы источника — «no network» в его выводе значит «без запросов к
  порталу», не «без трафика». Перед тяжёлым — сказать объём.
- **База из терминала:** `psql` есть (`/opt/homebrew/bin/psql`),
  `DATABASE_URL` брать из `.env.local` через `grep | cut`, не печатая. 07.10
  соединение было быстрым. Писать в базу — только в транзакции и с select
  после.
- **Песочница Claude Code (auto mode)** 07.10 не дала: править `.env.local`
  и запускать `npm test`. Тесты запускаются той же командой напрямую:
